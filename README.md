# Gameloft Legacy Formats
My research and documentation of legacy file formats used across **Gameloft games**

This repository "documents" following formats:
* `.PIG` - A 3D file format
* `.ANIM` - An anim file that must be applied directly on PIG files
* `.TGA` - Actually a PVR file with compression of data specified in the metadata, for unknown reasons kept as TGA by the developers

The formats documented here arent necessarily specified to a single game. Some of them have been used across different Gameloft games, but the main source of my research was **Minion Rush**

# ⚠️ WARNING
This is **NOT** a converter, extractor, or asset archive
It intentionally doesnt contain:
* The PIG/+ANIM/+TGA to GLB converter
* Game asset files
* External classes

This repository is intended **ONLY** for archival, research and documentation purposes, especially due to shutdown of one of my favourite games - Minion Rush
